Have you ever received a pop-up Christmas card? I wanted to convey the wonder of opening one through this digital experience.

You can also customize the text inside the card for sharing it with others to send a virtual greeting.

The model and animation were made in Blender by me, inspired by a real card, with AI generated textures.

The text animation is implemented with an algorithm inspired by Vara.js library, adapted for 3D, and employs the font SVG/JSON representation provided by the library itself.

The experience is optimized for mobile devices, providing a smooth and engaging experience on smartphones and tablets. It adapts to smaller screens, ensuring easy interaction and navigation on touch interfaces and can also be installed as PWA.

## Setup

```bash
# Install dependencies (only the first time)
npm install

# Run the local server at localhost:5173
npm run dev

# Build for production in the dist/ directory
npm run build
```
